# Data Directory

This repository does not redistribute the full third-party datasets.

- Place downloaded raw files in `data/raw/`.
- Store cleaned and joined tables in `data/processed/`.
- Commit only small, legally redistributable samples or derived features.
- Preserve dataset attribution and licences.

`sample_movie_features.csv` is synthetic and demonstrates the expected processed schema. Its values are illustrative and are not real measurements of the named example films.
