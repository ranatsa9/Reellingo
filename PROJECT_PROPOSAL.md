# Final Project Proposal

| Field | Content |
|---|---|
| **Project title** | **ReelLingo: Adaptive Language Learning Through Movies** |
| **Project idea** | An AI-powered learning app for Arabic-speaking students that transforms movie watching into personalized language practice. Users select favourite movies, interests, and current English ability. ReelLingo analyzes subtitle complexity and recommends a movie matching both the user's taste and an appropriate learning challenge. It introduces spoiler-free vocabulary before viewing, evaluates comprehension afterward, and updates future recommendations as the learner progresses. |
| **Who benefits** | Arabic-speaking university students seeking an engaging and affordable method for practising English vocabulary and listening comprehension. |
| **AI techniques** | NLP, subtitle-complexity analysis, text embeddings, supervised classification, linguistic clustering, collaborative filtering, hybrid recommendation, ensemble scoring, and grounded LLM-generated activities. |
| **Dataset** | MovieLens Latest Small, CMU Movie Summary Corpus, and a limited English–Arabic OPUS OpenSubtitles subset. |

## One-Sentence Pitch

Unlike streaming platforms that recommend only for entertainment, ReelLingo recommends the movie that offers the strongest balance between enjoyment and language improvement.

## Research Objective

To investigate whether combining movie preference with subtitle-derived linguistic suitability can create a more useful adaptive learning path than recommendations based only on popularity or entertainment preference.

## User Interaction

1. The learner selects favourite movies, a target language, and approximate ability.
2. ReelLingo recommends films using both taste and language fit.
3. The learner studies a small spoiler-free vocabulary pack.
4. The learner watches the film on an external platform.
5. A short activity measures vocabulary and comprehension.
6. The system updates the learner profile and adapts the next recommendation.

## Initial Scope

The initial two-week prototype supports Arabic-speaking students learning English with a catalogue of approximately 100–300 movies. Multilingual expansion is future work.
