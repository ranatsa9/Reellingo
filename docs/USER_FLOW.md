# ReelLingo User Flow

## Onboarding

1. Select native language.
2. Select target language.
3. Choose approximate ability or complete a short placement activity.
4. Rate or select five favourite movies.
5. Select a learning focus.

## Recommendation Session

1. Choose relaxed, balanced, or challenge mode.
2. Optionally select available time and genre.
3. Receive five ranked movies.
4. Inspect taste, language-fit, and learning-value explanations.

## Before Watching

1. Open the spoiler-free preparation pack.
2. Review five useful expressions.
3. Complete one short contextual question.

## After Watching

1. Complete vocabulary questions.
2. Complete general comprehension questions.
3. Rate enjoyment and perceived difficulty.
4. Receive a progress update.

## Adaptation

The next recommendation changes based on:

- Vocabulary recall
- Comprehension performance
- Perceived difficulty
- Enjoyment
- Dialogue-speed preference
- Recent movie history
